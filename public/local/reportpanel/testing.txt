local_reportpanel — manual test checklist
==========================================

SETUP
-----
[ ] Copy local/reportpanel to MOODLE/local/reportpanel
[ ] Site admin -> Notifications -> install runs clean (no XMLDB; no errors)
[ ] php admin/cli/purge_caches.php
[ ] After editing amd/src/*.js: grunt amd  (or confirm amd/build/*.min.js updated)

SETTINGS
--------
[ ] Settings page loads under Plugins -> Local plugins -> Report panel
[ ] Card URLs show relative defaults; editing one repoints the card
[ ] Disabling an external card hides it from the grid

PANEL (index.php)
-----------------
As ADMIN:
[ ] All 8 cards render; layout is a clean responsive grid; theme colours respected
[ ] Leaderboard / Site reports / Log report / Team reports / Badges open correct URLs (same tab)
As HR MANAGER (role per hrmanager.md):
[ ] Same 8 cards as admin
As TEAM MANAGER (edzteams:viewteam, no viewall):
[ ] Sees Team reports + Quiz/Cert/Consolidated/Leaderboard/Badges; Site reports & Log report hidden
As PLAIN LEARNER:
[ ] Sees Leaderboard, Quiz, Certificate, Consolidated, Badges; Site reports/Log/Team hidden
[ ] Guest / logged-out -> redirected to login

QUIZ REPORTS (quiz.php)
-----------------------
Full mode (admin/HR):
[ ] Category dropdown lists visible categories
[ ] Selecting a category AJAX-populates the course dropdown
[ ] Selecting a course lists quizzes: attempts (distinct users), highest, min, average grade
[ ] Numbers match a manual check on one quiz
[ ] Clicking quiz name opens /mod/quiz/report.php?id=CMID&mode=overview
[ ] Course with no quizzes -> friendly empty state
Self mode (learner):
[ ] No category/course pickers
[ ] Lists own quiz attempts across enrolled courses with own grade + last attempt date
[ ] Quiz name links to own review (or view if no attempt)

CERTIFICATE REPORTS (certificate.php)
-------------------------------------
Full mode:
[ ] category -> course cascade works
[ ] Lists customcerts with issued count
[ ] Clicking cert name opens /mod/customcert/view.php?id=CMID
Self mode:
[ ] Lists own issued certificates with issue date; name links to own cert view
[ ] No customcert installed -> graceful message (no fatal)

CONSOLIDATED USER REPORT (consolidated.php)
-------------------------------------------
Full mode:
[ ] User search typeahead returns name/email matches (min 2 chars)
[ ] Picking a user + submit shows table: Name, Email, Course, Completion %,
    Completion date, Grade, Certificate date, Badge(s)
[ ] Completion %, grade, cert date, badges verified against one real user
[ ] Download PDF: branded header band on every page; meta shows user, email,
    print date/time + printer; footer page x/y; landscape table readable
[ ] Download CSV: opens in Excel; columns + rows correct; UTF-8 names intact
Self mode (learner):
[ ] No search box; table is own data only
[ ] Direct hit of consolidated.php?userid=OTHER is blocked (forced to self)
[ ] PDF/CSV export own report works

SECURITY / EDGE
---------------
[ ] require_login + require_capability(local/reportpanel:view) on every page
[ ] AJAX get_courses / search_users require local/reportpanel:viewall
[ ] All output passed through format_string / s(); moodle_url for every link
[ ] PHP lint: php -l on every .php file -> no syntax errors
[ ] No PHP notices/warnings in error log during a full click-through

PRIVACY
-------
[ ] Privacy provider is null_provider (plugin stores no user data) and registers clean
